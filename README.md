# Hỗ trợ học sinh gặp khó khăn trong môn Toán ở các lớp 3-6

Web app song ngữ Anh–Việt cho giáo viên, chuyển thể từ
[Mathematics Intervention Toolkit](https://ies.ed.gov/ncee/rel/math-support-grades-3-6/intro)
(IES / REL Northeast & Islands, REL 2026-004, phạm vi công cộng) và
WWC Practice Guide 2021006. Đây là bản chuyển thể độc lập, không phải sản phẩm chính thức của IES.

Một file duy nhất: `index.html`. Mở trực tiếp bằng trình duyệt hoặc đăng lên bất kỳ dịch vụ web tĩnh nào.
